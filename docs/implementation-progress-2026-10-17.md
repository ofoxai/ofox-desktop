# 资源库工作台实施记录

本轮基于 `95b52931`，完善指令、MCP、Skills，版本保持 1.3.6，SQL schema 保持 v11。功能、状态与保留限制见[资源库工作台](library-workbench.md)。不增加项目配置、Hooks、子代理、RTK、路由或网关；原有未跟踪交接文件保持原样。

## 交付行为

- 三页共用紧凑筛选、真实工具 Logo、来源分组及次要操作菜单。Logo 只暂存增量，确认汇总预览后才应用；原有单项冲突、所有权、恢复入口仍保留。每个工具可选择不同指令集。
- 原生发现使用只读、限时、绑定来源证明的内存票据。导入重新核验，创建草稿而不接管原文件。损坏来源明确可见；Skills 同名异内容保留独立目录变体。
- 新增精选配置、普通 MCP 表单及可编辑指令模板。Skills 按所选目录导入并固定实际提交；浏览不执行资源或安装依赖。已有 MCP 编辑仍保持私密字段的保持／替换／清除语义。
- 批量按物理组组合完整写计划，同文件 MCP 一次写入，组内核验后 CAS 记账。取消保留成功组，中断只核对，剩余项重新预览。批次子日志不可由旧单项入口执行。备份恢复保留本机证据并提升 epoch。
- 选中导出使用独立命令，同时限制 manifest 和技能 artifact，旧后端不能静默导出全部。批次私有日志不进入新 SQL／WebDAV 导出及资源包。

## 回归与独立评审

先取得有意义的失败回归，再实现和复审，覆盖暂存而不提前写入、选择性导入、来源变化及读取失败、同文件多 MCP、兄弟资源撤回、指令物理冲突、Skills 变体与共享读取、取消与部分失败、写入后未记账、父子日志损坏、旧入口隔离和 epoch 失效。

专项补充覆盖：关闭未执行预览释放名额、StrictMode 与迟到响应清理、未参与批次的暂存选择保留、仅元数据变化摘要、旧后端缺失 epoch 的三页降级、连接结果按资源版本隔离、同类两个 Skills 的选中导出（逐文件解压核验未选哨兵不在包内），以及环境初始化未就绪时批量执行不得提前写沙箱配置。

前端独立复审无阻塞项，相关七文件 79 项及文案守卫 4 项通过。后端原生发现和批量协调交叉独立复审无剩余阻塞项；最后的命令环境屏障先取得两项失败再修正。全量门禁和安装结果由最终交付记录列明，不用专项结果替代。

最终前端 typecheck、format 和 140 文件／1109 项单测通过。最终 Rust fmt、all-targets Clippy（`-D warnings`）及 20 个 suite 全量测试通过：3059 通过、11 项按定义忽略。首次 Clippy 发现两项生产代码风格告警和测试切片的冗余 clone；等价修正后重新执行完整 Rust 门禁通过，没有增加 lint 豁免或跳过测试。安装和原生窗口复验结果单独绑定最终 SHA 记录；此前的构建或夹具截图不能替代。

## 原生验收补充：发现来源可辨识
