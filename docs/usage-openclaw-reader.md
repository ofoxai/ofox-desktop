# OpenClaw event-time reader contract

This integration targets OpenClaw 2026.10.3. The installed native SQLite API on Node 24.21.0 produced a temporary schema-24 database containing a version-4 transcript header and assistant messages stored as both TEXT and zstd. No agent, AI request, authorization or live configuration was used. The [small native payload fixture](../src-tauri/src/services/fixtures/openclaw-native-2026.10.3-events.json) retains that synthetic TEXT and compressed payload without local paths. Other regressions create isolated databases and transcripts.

The state root is separate from the configuration file path. An explicit application directory wins; otherwise the native `OPENCLAW_STATE_DIR` and `OPENCLAW_HOME` rules select state. `OPENCLAW_CONFIG_PATH` does not relocate sessions. Unreadable application settings stop root selection. Scans freeze the selected root before enumerating or reading native files.

Within `agents/<agent>/`, `agent/openclaw-agent.sqlite` is the primary store. A database-present session, including an empty window or an archive identity, suppresses a legacy `sessions/*.jsonl` copy. Only a bounded native first-line header identifies that copy; its obsolete body is not parsed. An unreadable or unsupported primary database is an error, never permission to fall back to stale JSONL. A strictly matched local source receipt also prevents a disappeared primary from reviving its agent's old projection; healthy agents can continue and coverage remains partial. That receipt is source-preference evidence, never an event acknowledgment. Agent ID, native session ID and native event ID form the identity; identical session IDs under two agents are separate scopes.

Native normalized `input`, `output`, `cacheRead` and `cacheWrite` are four independent buckets. Provider Responses shapes include caches in input and are normalized once. Reasoning is already part of output; context `totalTokens` is not a billable call total. Missing fields, model, event identity or timestamp produce explicit partial coverage. Unknown event time is never assigned today's date.

This slice imports token buckets, not the transcript's monetary `usage.cost` as authenticated provider billing. Its currency and billing provenance have not been established. Amount estimates remain subject to the existing price catalog and amount-coverage contract.

Spend reads all retained physical events, including messages outside the active context projection. Exact duplicate IDs count once; conflicting full native payloads are rejected even when their paid buckets agree. Native event IDs follow the vendor's whitespace trimming, while model and session strings retain their own semantics.

The reader does not reconstruct reset/deleted/cold archives or prove fork origins. Archive presence lowers coverage. Unknown fork seeds remain available in raw normalized partial results and do not enter the ledger. The original reader-only slice did not enable session/project analysis; the current [native analysis bridge](native-analysis-bridges.md) adds agent-scoped session identity, recorded project metadata and acknowledged own usage while preserving SQLite primary authority and the missing-primary fallback prohibition. Message counts and activity remain unavailable. A primary SQLite-only session does not gain an invented JSONL reading/navigation target.

This does not repair historical ledger rows or establish actual agent execution, Windows acceptance or final-source release polling performance. Native source bytes and SQLite sidecars are never modified; bounded main/WAL copies are queried in a temporary directory. Database or WAL leaf symlinks fail closed because alias-named sidecars cannot establish the target WAL snapshot. Relative native root overrides are unsupported because the desktop cannot recover the CLI's invocation directory.
