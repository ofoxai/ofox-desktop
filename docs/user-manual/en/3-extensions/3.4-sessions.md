# 3.4 Sessions

Choose **Sessions** in the main navigation to browse local history by tool and project. Recent activity determines list order. Rows show the title, models, Tokens, estimated cost and available actions. Discovery follows each tool's resolved configuration directory, including configured overrides.

## Find a conversation

The default title/path search immediately filters metadata, including IDs and models. Select chat content and press Enter or Search for an explicit local body scan. It searches user and assistant messages by default; tool and thinking content are optional. Content is not uploaded or stored in a persistent full-text index. Trash and arbitrary directories are excluded.

Body search reports progress and snippets, with cancellation and continuation. Time, decoded-size or result limits produce partial results. Changed, failed and unsupported sources are counted separately. Opening a hit validates its source revision; search again if the conversation changed.

## Read and export

Expand a row for files, model breakdown and continuation commands. **View content** opens a dedicated reader; returning preserves list filters and position. The reader provides Markdown, code/message copying, timestamps, a question index and in-session find. Process messages are collapsed and long transcripts are virtualized. Missing native facts are not inferred.

Raw HTML is not executed and images are not loaded from the network automatically. Markdown export uses the readable native projection; rewound messages and abandoned branches are not reconstructed.

## Continue, trash and usage

Supported sessions can continue in a terminal or provide a copyable command. Missing tools or directories have explicit reasons. A launch failure retains the command and next steps. Actions vary by provider and session.

Deletion first moves eligible files to OFox Trash, where they can be restored. Permanent cleanup requires a separate confirmation. Shared databases and uncertain ownership do not permit deletion. Native Codex archives support reading, search and export; they are separate from OFox Trash, and readability does not authorize continuation or deletion.

**View usage** locates the session within the current analysis range, with an explicit option to search all dates and tools. Returning from usage focuses the session row without automatically reading its body or starting a terminal.

## Interpretation

Main Tokens are fresh input plus output; cache reads and writes are separate. Costs use current OFox prices, not actual billing. Unknown prices display “—”; partial estimates carry “+”. Message/activity metrics remain unknown without reliable native evidence. See [known limitations](../../../known-limitations.md).
