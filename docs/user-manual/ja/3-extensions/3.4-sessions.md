# 3.4 セッション管理

メインナビゲーションの **セッション** から、ツールとプロジェクト別にローカル履歴を確認できます。最近の活動順に、タイトル、モデル、Tokens、見積額、利用可能な操作を表示します。設定したカスタムディレクトリを含め、各ツールの解決済み設定先を使用します。

## セッションを探す

既定のタイトル・パス検索は、IDやモデルを含むメタデータを即時に絞り込みます。会話内容の検索はキーワード入力後に Enter または検索ボタンで開始します。既定ではユーザーとアシスタントの本文のみを検索し、ツールと思考過程は任意で含めます。本文のアップロードや永続的な全文索引の作成は行いません。ゴミ箱や任意のディレクトリは検索しません。

本文検索は進捗と抜粋を表示し、中止と続行に対応します。時間・展開後サイズ・結果数の制限では部分結果と表示します。変更、読取失敗、未対応ソースは個別に報告します。抜粋を開く際にソースの版を確認し、変更されていれば再検索を案内します。

## 読む・書き出す

行を展開するとファイル、モデル内訳、再開コマンドを確認できます。**内容を表示** で専用の閲覧画面を開き、戻ると一覧の条件と位置を保持します。Markdown、コード・メッセージのコピー、時刻、質問の目次、会話内検索に対応します。処理過程は既定で折りたたみ、長い履歴は仮想化します。元の記録にない情報は推定しません。

生のHTMLは実行せず、画像は自動でネットワークから読み込みません。Markdown書き出しは読み取れるネイティブの投影を使い、巻き戻されたメッセージや破棄された分岐を復元しません。

## 再開・ゴミ箱・使用量

対応する会話はターミナルで再開するか、再開コマンドをコピーできます。ツールやディレクトリが利用できない場合は理由を表示します。起動失敗時もコマンドと次の手順を保持します。すべてのツールが全操作に対応するわけではありません。

削除はまずOFoxのゴミ箱へ移動し、復元できます。完全削除は別の確認操作です。共有データベースや所有範囲を確認できない記録は削除できません。Codexのネイティブアーカイブは閲覧・検索・書き出しに対応します。OFoxのゴミ箱とは別であり、閲覧可能でも再開・削除が許可されるとは限りません。

**使用量を表示** は現在の分析範囲でセッションを特定します。範囲外の場合は全期間・全ツールを明示的に選択できます。使用量から会話に戻る際は行にフォーカスし、本文の自動読込やターミナル起動は行いません。

## 数値の意味

主Tokensは新規入力と出力の合計です。キャッシュ読書きは別に表示します。金額は現在のOFox価格による見積りで、実際の請求額ではありません。未知の価格は「—」、部分見積りは「＋」を表示します。信頼できるネイティブ情報がないメッセージ数・活動量は不明のままです。[既知の制限](../../../known-limitations.md)も参照してください。
