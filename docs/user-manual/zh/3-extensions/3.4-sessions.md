# 3.4 会话管理

在主导航选择 **会话**，按工具和项目浏览本机历史。列表按最近活跃时间排列，显示标题、模型、Tokens、估算费用和可用操作。数据来自各工具解析后的配置目录；自定义目录也遵循工具设置。

## 找到会话

默认“标题与路径”即时搜索标题、ID、目录和模型。“聊天内容”需要输入关键词后按 Enter 或点击搜索，默认只匹配用户和助手正文；可主动包含工具与思考过程。搜索只在本机进行，不上传正文、不建立持久化全文索引，也不扫描回收站或任意目录。

正文搜索显示扫描进度和匹配片段，可取消或继续扫描。达到时间、解码大小或结果预算时显示部分结果；变化、读取失败和不支持的来源分别报告，不会冒充没有结果。点击片段前会核验来源版本；会话变化时请重新搜索。

## 阅读与导出

展开会话查看文件、模型和继续命令，点击 **查看内容** 进入独立阅读视图。返回时保留列表条件与位置。阅读器支持 Markdown、代码与消息复制、时间、提问目录和本会话查找；工具与思考过程默认折叠，长历史按需渲染。原生记录没有的信息不推断补齐。

正文中的原始 HTML 不执行，图片不自动联网加载。Markdown 导出保存可读取的原生投影，不会恢复已经撤回的消息或废弃分支。

## 继续、回收站与用量

支持的会话可在终端继续，也可复制继续命令；工具或目录不可用时显示原因。启动失败会保留可复制命令和下一步提示。不是每种工具都支持所有动作。

删除先移入 OFox 回收站，支持恢复；永久清理是独立确认操作。共享数据库或安全边界无法确认的会话不开放删除。Codex 的原生归档可以读取、搜索和导出；原生归档不等于 OFox 回收站，不会因可读就自动开放继续或删除。

**查看用量** 可定位该会话在当前分析范围内的统计；范围不匹配时可以明确选择全部时间和工具。用量页跳回会话只定位行，不会自动读取正文或启动终端。

## 统计口径

主 Tokens 为新输入加输出，缓存读写单列。费用是 OFox 当前价格估算，不是实际账单；未知价格为“—”，部分计价带“＋”。消息与活动缺少可靠原生依据时保持未知。更多覆盖边界见[已知限制](../../../known-limitations.md)。
