# 回复渲染修复（阶段 1、2）

日期：2026-11-09　分支：`fix/assistant-markdown-render`（自 `feat/assistant-1.5.1` de8f9cc1）

## 为什么做

用户真机截图里两类问题，已用本机原回复复现：

1. **中文加粗失效**：`**说明：**正文`、`**多头注意力（MHA）**后面`、`卡在**「推送镜像」**这一步`。CommonMark 规定收尾的 `**`
   前面是标点、后面紧跟文字时不能收尾（开头同理），中文天天这么写。本机 107 条助手回复 5 条中招，抽样 4000 条 Claude Code 回复 6 条，全是中文。
2. **公式吞掉后文**：`$$公式…⏎…公式$$` 的开头、收尾 `$$` 都没单独占行，remark-math 只丢掉首行然后一直吞到回复末尾，
   之后的正文、表格、标题全被当公式，KaTeX 失败，整段红字。

同类问题（顺带修）：

3. `**http://localhost:3000**，打开即可`：GFM 网址识别到空白才停，`**，打开即可` 被吞进网址，加粗失效。现有的网址尾巴修正在解析之后，救不回来。
4. 单独一行的 `$$E=mc^2$$` 被当成行内小公式（不居中）。
5. 表格里的 `$|x|$`：竖线把单元格切开。
6. 公式出错时整段红色（KaTeX 默认 `#cc0000`）。
7. 没有收尾的 `$$`（模型漏写）同样会吞掉后文。

参考：dsh 在解析层处理中文加粗、给网址识别打补丁（遇非 ASCII 标点即止）、公式多种写法做成分隔符扩展；
AionUi 只做了 `\[ \]` 改写。我们保持 react-markdown，借用思路，不抄代码。

## 规则

| # | 改动 | 位置 |

| B | 解析前切断网址：正文里（代码外、链接目标外）的裸网址遇到全角标点即止，去掉其前的 `*_~` 与 ASCII 句末标点，写成 `<url>`（`www.` 写成 `[www…](http://www…)`）；没有全角标点紧跟的网址不动 | `markdownUrls.ts`（与公式共用 `markdownSource.ts` 的代码识别） |
| C | `$$` 整理：开头 `$$` 在行首（前面只有空白、`>`）且公式跨行、或收尾 `$$` 后到行尾只有空白 → 改成开头、收尾各占一行的公式块（保留引用/缩进前缀）；收尾后还有文字时，文字另起一段；行中的 `$$…$$` 仍是行内公式 | `markdownMath.ts` |

## 遗留（小问题，后续处理）

- 句中孤立 `$$` 紧挨下一行的公式块时，配对会错位（与改写前的配对规则相同，形态上无法与 `公式为 $$…⏎$$` 区分）。
- CRLF 换行的 `$$` 独占行未识别为公式块边界。
- 表格行里有 `$$` 时紧跟的公式块会被转义。
- 超过 512 字的表格分隔行不再识别（改写前也不识别）。
- 注释、CDATA、属性值里出现 `<` 时，其后紧跟全角标点的网址会被加上 `<…>`。
- `splitCode` 对代码行也统计 `$$`（极端输入约 50 ms），可加 `includes("$$")` 快速判断。
- 链接文字跨行、`-\t` 列表标记、嵌套在非链接方括号里的网址。
- 阶段 3（流式）：正在写的段落先不渲染公式、冻结已写完的段落（参考 dsh）。

## 阶段 3：流式渲染（2026-11-09，用户批准，参考 dsh）

分支 `feat/assistant-streaming-render`（自 ffd2add5）。

现状：回复每帧（requestAnimationFrame，最多 60 次/秒）整条重新解析、重新渲染，所有公式重算；写到一半的公式块会闪烁。

做法（借 dsh 的思路，不抄代码）：

1. **按块渲染**：用和渲染器相同的解析插件把（改写后的）正文切成顶层块（段落、列表、表格、公式块、代码块……），每块单独渲染并缓存；
   块的内容没变就不重算。块直接渲染在同一个外层元素里，不加包裹元素，页面结构与整段渲染一致（外层“首尾元素去边距”的样式照常生效）。
2. **正在写的块**：流式时最后一块的公式显示为源码（不调用 KaTeX）；写到一半、还没收尾的公式块整体显示为源码，不吞后文。
3. **结束时**：只有最后一块改为渲染公式，前面的块不动，不闪、不跳。
4. **回退**：正文里有引用式链接定义或脚注定义（跨块）时，整段渲染。
5. `components`、`urlTransform` 保持引用稳定，缓存才有效。

测试：
- 流式中各前缀渲染：除最后一块外，页面元素与最终渲染逐个一致（dsh 的“任意前缀一致”）。
- 流式中最后一块的公式是源码、无 KaTeX 报错；前面块的公式已渲染。
- 写到一半的公式块显示为源码，后续块不受影响。
- 有引用定义/脚注时回退整段渲染。
- 一次性对比：3107 条真实回复，按块渲染与整段渲染的 HTML 一致。
- 手动测流式每帧耗时（长公式回复），前后对比。
