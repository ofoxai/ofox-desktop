# 侧栏导航、页面标题和加载小狐狸

## 为什么做

本机试用 #1460 的宽布局后，用户的反馈是「太靠近顶栏了，整个 UI 还是太奇怪了」，并拿 magpie 做对比：「magpie 就不会显得那么紧迫」。

具体问题：
- 宽布局拿掉了顶栏，但各页面的上边距还按「上面有顶栏」留（`pt-1`，4px）。工具页的账户卡、用量页的筛选直接贴着窗口上沿。
- 左边 80px 的图标条，图标下面一行小字，看起来别扭。
- 页面里的子页（用量的「概览 / 明细 / 会话分析」、资源库的「指令 / MCP / 技能」）挤在内容顶部的一排 tab 里，和周期、筛选按钮混在一起。
- 加载时只有一行灰字「加载中…」，页面大片空白。magpie 在骨架上有一只会动的小鸟，等待不无聊。

用户的要求是参考 magpie 的结构，但不要一模一样，要带上 Ofox 自己的品牌和产品特点。

## 目标

- 所有窗口宽度都用左侧栏导航，不再有顶部导航。侧栏带文字、分组，可以收起。
- 当前页面的子页列在侧栏里，在这个页面下面。
- 每个页面上方有大标题和一句说明，页面操作放在标题右边。内容和窗口上沿、侧栏之间留出空间。
- Ofox 的特色：侧栏顶部放账户和余额，当前页用 Ofox 的浅橙色高亮。
- 助手页三栏：侧栏、可以收起的对话列表、对话区。
- 整页或整块数据第一次加载时，显示一只会动、可爱的小狐狸。

## 不做的

- 不改各页面的业务行为：绑定、用量统计、会话、资源库、助手对话都照旧，只改导航、标题、间距和加载样子。下面「页面内的调整」列出的几处排版改动除外。
- 不新增设置项。侧栏收起和对话列表收起只记在本机。
- 不做 Windows、Linux 的自定义标题栏。这两个平台仍然用系统标题栏。
- 按钮里的小转圈、列表里的行内加载不换成狐狸。
- 托盘弹窗不改。

## 反目标（技术上能用也算失败）

- 看起来和 magpie 一模一样：magpie 是左上角写名字、白色药丸高亮当前页、内容上方显示「a / b / c」路径。这三处都要换成 Ofox 自己的做法。
- 内容仍然贴着窗口上沿或侧栏边。
- 助手被摆成最主要的功能，比如放在侧栏第一个。
- 切换页面、子页或收起侧栏时，丢掉页面状态：正在输入的草稿、正在进行的回复、滚动位置、筛选条件、展开状态。现在各页面首次打开后就一直挂着、只是隐藏，这一点保持不变。
- macOS 的红绿灯压住侧栏内容，或者窗口拖不动。
- 小狐狸在系统开启「减弱动态效果」时仍然在动。

## 约束

- Tauri 2 应用。macOS 用 `titleBarStyle: "Overlay"`，红绿灯在 (14,17)，大约占到 x≈68px。窗口最小 900×600（`src-tauri/tauri.conf.json`）。
- 现在的外框：`src/components/shell/ShellFrame.tsx` 按 `useShellLayout()`（1280 / 1240 滞后）在 `AppHeader`（顶栏）和 `AppRail`（80px 图标条）之间切换。页面面板在 `src/components/console/ConsolePage.tsx`，是 `role="tabpanel"`，导航是它们的 tab。两种形态下的面板放在同一棵树里，切换时不会重新挂载。
- 助手页的宽布局（#1460）：对话列表是 `AssistantSidebar`，收起状态存在 `ofox.assistant.sidebarCollapsed`。对话区的字号和尺寸是 CSS 变量（`--fs-*`、`--icon-btn`、`--ctl-h`），宽窗口时换成大一号的值。
- 颜色用 `src/index.css` 里的 token（`canvas`、`line`、`ink-*`、`brand`、`brand-soft`、`brand-ink`），浅色和深色都要好看。
- 所有可见文字走 i18n（中、英、日）。项目开源：可以借鉴 magpie 的结构，但不搬它的代码和图形；狐狸用 Ofox 自己的标志画。
- OFox 的地址（充值、账户）一律用 `src/lib/ofoxUrls.ts` + `useOfoxApex` 按区域生成，不写死 `.ai` 或 `.io`。
- 每次提交要通过 typecheck、Prettier、前端单测。

## 用户定下来的

- 整体按 magpie 的结构来：带文字的分组侧栏，子页列在侧栏里，内容区留白。
- 标题采用「A + B」组合：
  - **A**：内容上方是页面大标题，下面一句说明，比如「用量概览」+「各工具这段时间用了多少 token、花了多少钱」。当前页高亮用浅橙底、橙色图标、加粗文字，不用 magpie 的白色药丸，也不用「a / b / c」路径。
  - **B**：侧栏顶部放账户块，内容是头像、名字和余额。
- 助手页用三栏：侧栏、对话列表、对话区。助手不是最主要的功能。历史对话列表做成可以折叠、隐藏的形式。
- 窄窗口也用侧栏，侧栏可以收起。
- 加载动画用「歪头抖耳朵」，要可爱。定稿的样子是 `loader-cute.html`：
  - 五官：几何狐狸加上会眨的眼睛（带高光）、腮红、浅色口鼻、小嘴，耳朵内侧是浅橙色。
  - 动作：先轻轻蹦一下，落地时有挤压；然后歪头抖左耳，再抖右耳，循环播放。脚下有影子，跟着蹦跳缩放。
  - 下面是一条来回走的橙色进度线，配一句说明，比如「正在读取用量…」。
  - 系统开了「减弱动态效果」时，狐狸静止。

浏览器草图在 worktree 里，不进 git：`.superpowers/brainstorm/18440-1793792468/content/`。
- `layout.html`：整体结构。其中标题样式后来被 A+B 取代。
- `title.html`：标题的 A、B、C 三个方案。
- `assistant.html`：助手页的三种摆法，选的是第 2 种。
- `loader-cute.html`：小狐狸的定稿。

## 我的判断（用户可以改）

### 侧栏

- 展开时宽 216px，从上到下依次是：
  1. 顶部一行，高约 52px，可以拖动窗口。macOS 上左边给红绿灯留位，右边是收起按钮。
  2. 账户块：头像（没有头像时用浅橙圆底加狐狸），名字，一行橙色的「余额 $923.80」。
     - 点账户块弹出一个小菜单：充值（打开按区域生成的钱包地址）、刷新余额、账户设置（打开现有的设置对话框）。
     - 本地模式或未登录时，账户块换成「登录 Ofox」按钮，走现有的 `onLoginRequested`。
  3. 分组导航。
     - 「使用」组：工具、会话、资源库、助手。
     - 「观测」组：用量。
  4. 底部：新版本提示（现在的 `UpdatePill`，做成一整行），设置。
- 子页只在当前页下面展开，缩进显示，不带图标。当前子页用橙色文字。
  - 用量的子页：概览、明细、会话分析，沿用现在的条件，`requestSupported`、`analysisSupported` 为假时不显示对应子页。
  - 资源库的子页：指令、MCP、技能，后面跟数量。
  - 工具、会话、助手没有子页。会话的「回收站」仍是页面里的按钮。
- 收起后是 80px 宽的图标条：只显示图标，鼠标悬停显示名字，账户块缩成头像。
  - 取 80px 是因为红绿灯要占约 68px，和现在 `AppRail` 的理由一样。
  - 收起状态记在本机，比如 `ofox.shell.sidebarCollapsed`。默认展开，不按窗口宽度自动收起。
  - 收起后怎么进子页：鼠标悬停或键盘聚焦到图标时，旁边弹出一个小浮层，第一行是页面名，下面列出它的子页，可以直接点或用键盘选。点图标本身仍然是进入这个页面，回到上次停留的子页。
- 本地模式下账户块的三种样子：
  - 未登录：显示「登录 Ofox」，走现有的 `onLoginRequested`。
  - 已登录但跳过了绑定（`localOnly && localSignedIn`）：显示「绑定工具」，文案沿用 `toolCatalog.bindOptional`，走同一个 `onLoginRequested`。不为了显示余额在本地模式新增账户请求。
  - 正常绑定模式：头像、名字、余额，见上。
- 原来挤在页面顶部的那排子页 tab（用量的 `SegmentedNav`、资源库的 `SegmentedNav`）去掉。子页状态改由侧栏控制，原来记住的选择（比如 `ofox.usageTab`）继续沿用。
- `AppHeader`、`AppRail` 和窄 / 宽两套导航都由新侧栏取代。外框不再按窗口宽度切换导航。`useShellLayout` 只剩一个用处：判断助手对话区要不要用大一号的字号和尺寸。

### 页面标题

- 每个页面（助手除外）的内容最上方：
  - 大标题约 20px，粗体；下面一句说明，用 `ink-muted` 色、12px。
  - 标题右边放这个页面的操作。
- 标题区距窗口上沿约 40px（和侧栏顶部那行对齐），macOS 上这一块可以拖动窗口。
- 页面内容左右留约 28px，内容最宽约 1120px，大屏上居中。用量这类图表页可以更宽，由实现者决定。
- 有子页时，标题写成「用量概览 / 用量明细 / 会话分析」，「资源库 · 技能」这样的写法也可以。说明跟着子页换。具体文案由实现者写，交给用户过目。
- 各页标题右边的操作：
  - 工具：方案 ▾、添加、刷新。方案和添加从列表上方挪过来。
  - 会话：刷新。
  - 资源库：现在页面头部右侧的那几项（情景向导、发现 / 模板等）和刷新。
  - 用量：自动刷新间隔和刷新。
- 刷新按钮原来在顶栏或图标条里，调用 `shell.refresh()`，现在挪到各页标题右边，行为不变。

### 页面内的调整

- 工具页：顶部的账户卡片去掉，因为侧栏已经有账户和余额，不再重复显示。如果余额加载失败、需要重试，就在侧栏的账户块里显示。
- 用量页：
  - 工具筛选从一排工具按钮收成下拉框，和「全部模型」「全部项目」一样。
  - 周期、筛选和估价放在同一行，日期范围和时区那行小字放在下面。
  - 第一张草图里画了这个改动，用户没有反对。

### 助手页

- 三栏：侧栏、对话列表（约 260px，现有的 `AssistantSidebar`）、对话区。
- 对话区左上角有按钮，可以收起或展开对话列表，继续用 `ofox.assistant.sidebarCollapsed` 记住状态。
  - 列表展开时，当前对话在列表里高亮。
  - 列表收起时，对话区顶部显示对话标题。这一点和 #1460 现在的行为一样。
- 助手页没有上面说的大标题，对话区顶部那一行保持 #1460 的样子。
- 助手原来靠图标条上的刷新按钮重新读取对话列表和当前对话（`AssistantPage` 里注册的 refresh）。图标条没了以后，把「刷新」放进对话区顶部的「⋯」菜单，顶部那一行看起来不变。
- 助手页在窄窗口下和其他页面一样，用新侧栏，不再用顶部导航。
- 窗口很窄时，比如 900px、侧栏和列表都展开，对话区会比较挤，由用户自己收起侧栏或列表，不做自动收起。
- #1460 窄布局里「带外框的列表 + 对话面板」那套样式不再需要，两种宽度都用无外框的三栏。字号仍按宽度切换。

### 小狐狸加载

- 新组件 `FoxLoader`，有两个尺寸：
  - 页面级：约 60px，带进度线和说明文字。
  - 卡片 / 区块级：约 36px，不带进度线，说明文字可选。
- 狐狸用 SVG 画，基于 `ofox-logo.png` 的形状：两只三角耳朵加菱形脸。动画用 CSS keyframes，参数照 `loader-cute.html`。用 `prefers-reduced-motion` 关掉动画。
- 说明文字放在 i18n 里，按场景写，比如「正在读取用量…」「正在找你的会话…」「正在读取资源库…」，没有合适场景时用通用的「加载中…」。
- 替换范围：页面或整块数据第一次加载、还没有任何内容可显示的地方。大致有：
  - 用量的各子页；
  - 会话列表和会话内容；
  - 资源库各子页；
  - 工具页的工具列表；
  - 助手打开对话时。
  - 具体清单由实现者逐个确认。已有数据、只是在后台刷新时，不出狐狸。
- 很快就加载完的情况：开始加载约 200ms 后还没好才显示狐狸，免得一闪而过；狐狸一旦出现，至少停留约 600ms，让它把一次动作做完，不会刚冒头就消失。

## 交给实现者

- 组件怎么拆，比如 `AppSidebar`、`PageHeader`、`FoxLoader`，以及侧栏和页面之间怎么传子页状态。可以在 `ShellContext` 里加每个页面的当前子页，也可以由页面向外框注册子页列表。
- 侧栏的具体间距、图标（lucide）、悬停和按下的样子、深色模式下的颜色深浅，只要沿用现有 token，并符合上面的「浅橙高亮」。
- 账户块菜单的具体样式。
- 怎么保证 tab / tabpanel 的无障碍关系和键盘操作。侧栏和子页都要能用键盘切换。
- 测试怎么组织。

## 怎么验收

- 单测：
  - 侧栏导航切换页面；子页切换并且记住选择。
  - 收起和展开侧栏后，状态被记住；收起后仍能导航，悬停能看到名字。
  - 切换页面、子页、收起侧栏，都不丢页面状态。
  - 账户块在三种状态下的显示：已登录、余额加载失败、未登录。
  - `FoxLoader` 在减弱动态效果时不动。
- 在 Chrome 页面里，按 900px、1280px、1512px、1920px 四种宽度，浅色和深色各截一次图：
  - 内容不贴窗口上沿和侧栏边；
  - 红绿灯位置没有压住东西；
  - 助手三栏在列表展开和收起时都正常。
- 本机试用：macOS 全屏、最大化、普通窗口和最小窗口都试一遍，窗口能拖动。按项目规则，等用户说「提交」后再做 Windows 编译和试用。
