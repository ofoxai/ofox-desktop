# PPT 自编风格示例预览

> 2026-11-10 后续更正：本记录中的八页仅为自行编写的风格示例，不能用于证明上游原模板完整性或原生适配覆盖。当前 UI 将其标为“原生风格示例”；上游原模板另按真实文件的 10/10/7/8/6 页提供全部页面预览，见[来源覆盖审计](2026-11-10-ppt-source-coverage-audit.md)。真实用户文件由右侧文件工作区按实际文件页数读取，见本轮实施验收记录。

初版风格库只提供封面和内容页两张图片，并在预览窗口纵向排列。封面高度接近可视区域，内容页和滚动入口不明显，用户容易把它理解为只有封面。

本轮将六种已开放原生风格的预览扩为同内容的八页完整示例：封面、目录与章节、要点内容、对比、图表、流程、公式、总结。这里的“完整”指这一份示例的全部页面；不代表覆盖上游模板所有版式，也不表示尚未生成的用户 PPT 已能预览。五种新增风格保持实验标识，其他十九项候选仍不开放。

## 页面与交互

每种风格使用有序 `pages` 元数据。界面从数组读取页数，不硬编码八页；目录卡片继续显示封面，完整预览只显示当前一张大图，并提供缩略图导航、上一页、下一页与当前页码。大图在有界窗口内使用 `object-contain`，完整保留四边，不依赖主图区域滚动。

方向键和 Home / End 只在预览窗口内翻页；缩略图导航有独立滚动区域及当前页状态。首末页按钮禁用时，焦点转到稳定的预览区域。每个页面拥有独立图片加载状态，旧页面迟到的事件不污染新页；坏图可以重试或跳过。查看和翻页不更改已选风格，只有“使用”会提交选择。关闭、会话切换与账户权限变化沿用原有关闭和焦点约束。

新增 React 组件复核使用 `react-best-practices` 技能，重点检查静态资源、状态归属、图片加载与键盘焦点；没有加入新的运行依赖。

## 素材与边界

素材由当前已验证的 Python / OfficeCLI 生成链路离线制作，使用独立自编的统一内容。主图目标为 1920×1080，缩略图为 320×180；六套八页对应 48 张主图与 48 张缩略图。图表使用明确标注的自编示意数据。数学页保留源 PPTX 的原生数学结构，图片预览使用已有兼容回退，不把图片作为可编辑公式的证明。

这次不修改生成器、模型路由、账户端点、权限或消息请求结构。预览在本地完成，不发送消息、不调用模型。来源和许可继续见 [素材说明](../../../src/assets/presentation-styles/NOTICE.md)。原生结构、实际尺寸、图片哈希、逐页检查与新签名包验证收据存放在 `.real-eval/ppt-full-preview-2026-11-10/`，最终结果随验收补录。
