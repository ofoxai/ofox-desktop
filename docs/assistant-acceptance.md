## 原生桌面场景

macOS 和 Windows 分别使用专用测试配置与测试账号。开发构建须显式指定新的
`CC_SWITCH_TEST_HOME`，使用调试凭据文件；不得设置 `OFOX_DEV_USE_KEYCHAIN`，也
不得复制日常账号凭据到源码包。真实请求需有测试账号和可用助手 Key。记录实际
请求是否收费；本地模拟服务通过不代表真实账单已核对。

| 场景 | 通过条件 |
| --- | --- |
| 首次启动、`.ai` / `.io`、区域切换和重启 | 登录/目录/请求地址随选定区域解析；旧请求不覆盖新身份 |
| 多轮聊天和模型切换 | 上下文保留；流式输出、停止、重试、编辑重发、重新生成可用 |
| 图片、中文文本、PDF、DOCX/XLSX/PPTX | 真实附件可读；不支持、超限、损坏、不完整和纯文字范围有明确提示 |
| 联网搜索和网页读取 | 来源能打开；只读取当前会话允许的页面；计费次数和原始单价保留 |
| 搜索状态不明与失败后重启 | 不自动重试收费操作；失败原因与“可能已计费”提示保留 |
| 历史搜索、重命名、草稿、回收站 | 列表正确；切换和重启不丢草稿；回收站只读，可恢复 |
| Markdown 原生保存与取消 | 文件可读，包含来源和附件清单；取消无新增错误或成功提示 |
| ZIP 原生保存与取消 | 草稿先保存；包含历史版本、附件和 operations；无凭据文件 |
| 空测试配置恢复并重启续聊 | 旧消息和附件可用；搜索单价及历史费用不随新目录价格改变 |
| 重复恢复、同 ID 冲突、部分成功 | 相同内容跳过；冲突不覆盖；已成功导入的会话可保留和重试 |
| 永久删除 | 仅删除专用测试会话；附件/native 历史无残留；取消和 Escape 恢复焦点 |
| 900×600、zh/en/ja、明暗主题、键盘 | 不横向溢出；多附件输入区可滚动；控件和费用可见；Tab/Shift+Tab/Enter/Escape 可用 |
| 未登录与旧功能回归 | 助手提示登录；已有本机工具功能仍可用；不暴露配置助手入口 |

截图只包含测试数据。账号切换、取消和部分恢复必须单独记录；仅能打开页面不足以
