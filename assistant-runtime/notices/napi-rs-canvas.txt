@napi-rs/canvas 1.0.13
======================

Ofox Desktop's assistant runtime renders PDF pages that have no extractable
text with @napi-rs/canvas, a Node.js binding for the Skia graphics library.

- runtime/node_modules/@napi-rs/canvas/ is MIT licensed:
  Copyright (c) 2020 lynweklm@gmail.com (full text in its LICENSE file and
  at the end of this notice).
- runtime/node_modules/@napi-rs/canvas-<platform>/ holds the native addon
  (skia.<platform>.node). It statically links Skia and the components below.
  The sbom.cdx.json file next to the addon lists every linked component with
  its version and license.

The sections below give the notices those components require.
