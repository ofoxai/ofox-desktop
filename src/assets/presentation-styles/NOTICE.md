# Presentation style previews

These 96 JPEG raster images show original Chinese sample content authored for
Ofox and rendered offline from its actual native Python presentation helpers.
Each of six styles has one complete eight-page example: cover, chapter/outline,
content, comparison, chart, process, equation and closing. Each page has a
1920×1080 main preview and a 320×180 thumbnail. They are representative previews,
not editable slide files, complete upstream template conversions, or quality
certifications for arbitrary generated content.

The common sample discusses a problem, evidence and an action. It contains no
closed-source agent content, customer data, imported illustrations or logos.
Sample text and diagrams are native objects in the source decks. The chart has
an embedded workbook with independently authored illustrative values 30/45/25,
not measured data. Chart categories 01/02/03 have native Chinese mapping labels.
The formulas retain native OMML and noneditable PNG compatibility fallbacks;
the raster previews select those existing fallbacks in a private rendering copy.
No native-editing claim is inferred from these JPEGs. No font binaries were downloaded, imported
or embedded for these assets. Native font slots can use local system fallback.
